# Neighborhood Monopoly

Frontend-only React prototype. See `project.md` for full product vision and scope.

## Run locally

```bash
npm install
npm run dev
```

## Stack

- React + TypeScript + Vite
- React Router (navigation, bottom tabs)
- Zustand (shared client-side demo state)

All data is mocked locally in `src/data/`. No backend, auth, or real APIs.
